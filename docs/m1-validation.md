# M1 离线验收

测试环境为 Ubuntu 22.04.5 x86_64、GCC 11.4、CMake 3.22.1、系统 yaml-cpp 0.7。候选版本 0.0.0-rc.1。两种构建各在单独的空构建目录从本地依赖完成。每种配置的 4 项 CTest 均通过。

| 检查 | 观测 |
| --- | --- |
| 六轴部署配置 | 输入 66 B，输出 42 B，每拍 19 帧、2125 bit，1 Mbit/s 下占 8 ms 的 26.56%。另预留 7 帧心跳、1 帧 EMCY 与 1 对 SDO 请求/应答共 860 bit。 |
| 图像与字典 | config_image_and_od 核对 42 个变量的名称、对象、帧内及绝对字节位置，逐轴交换含负数和未对齐字段的原始字节。通过栈的 OD 查询函数检查 18 个镜像的每个可映射字节及方向。 |
| 边界与错误 | config_cli_boundaries 经主程序验证 50/51 个槽、双方向 0、25/26 个变量、字典容量及配置文件、CLI 各类反例，覆盖后重新计算线时。 |
| 硬件隔离 | 在没有 can0 的机器检查完整六轴示例，退出码 0。使用 strace 监测 socket、connect、bind，记录为 0 条。 |
| 可复现性 | 两个子模块在构建后均为干净工作树。重新生成的两个 OD 文件 SHA-256 与前次一致。指定不存在的 CANopenNode 目录时，CMake 报出确切目录与初始化命令。 |
| 版本及依赖 | 两种构建识别同一完整内测版本；依赖 SHA、许可证和 yaml-cpp 版本写入各自的 dependencies.txt。 |

复验使用实施计划中的 debug/release preset 和 CTest 命令。初始化策略按设备清单核验对象，eRob 可选对象为 0x607C、0x6083、0x6084、0x6085，六轴示例配置的初始化命令为空。以上数据是配置和软件证据，线上相位和实际停稳时间由 M5 测量。
