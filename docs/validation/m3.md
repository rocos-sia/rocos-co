# M3 · SHM v2 与主站程序

0.0.0-rc.3 在 Ubuntu 22.04.5 通过 24 项 CTest（6 项 unit、1 项 ipc、17 项 vcan）。集成客户端单独编译，使用实际 rocos-app/3rdparty/rocos-shm/include，对应公共提交 14618b7。公共库的 rocos_shm_v2 另行通过，涵盖错误 ABI/长度、所有权、重启实例及跨进程邮箱。正式 CLI 在打开 CAN 之前取得 SHM owner 锁，失败时按实例归属清理资源。

| 验收内容 | 直接观测 |
| --- | --- |
| SHM ID、初始发布、过程映像 | 使用进程唯一测试 ID；ready 前连接失败、同 ID 第二 owner 失败。客户端确认 header 80 B、bus 220088 B、dt 8000 µs、Input 66 B、Output 42 B。在第一次槽 8 通知后读出六个不同的负位置，初始目标与实际位置对齐。六轴各写不同目标，模拟驱动在后续 SYNC 返回对应值。 |
| 后端与诊断 | co=3；六节点身份在线读回，当前 AL=0、无状态切换能力、WKC/DC 无有效指标。只读连接不能消费槽 8。唯一可写 App 是 v2 部署约定，公共库的 owner 锁约束主站实例，联调只启动一个写端。 |
| 中断及时间戳 | 第 5 轴持续缺少必需 TPDO 时，客户端验证旧输入的 Unix 时间戳冻结、槽 8 无新通知、ready 仍为 1、主站单调心跳继续推进。 |
| PREOP 邮箱 | SDO 读取 1/64 B、容量不足、请求 65 B、禁止映射写、设备允许清单参数写后读回、有效远端 abort、旧实例拒绝。读响应延迟时保留原事务并 poll；已送出的写丢应答时返回 TIMEOUT_UNKNOWN，未重发。OP 对 SDO 返回 STATE_MISMATCH，RESET_STATS 在边界确认。 |
| 输出与安装 | 从独立临时前缀安装的可执行文件，在其他工作目录用绝对路径加载随包六轴示例。包含配置、设计、依赖记录、许可证。重定向输出无 ANSI，主站错误返回非零；显式使用不存在的接口后测试 IPC 资源均已清理。 |

[公共规范仓库](../../../rocos-shm/docs/abi-v2.md)的配套本地提交 66e8c5d 登记数值 3，并更新 SHM 监控的身份显示。现有 App 的 Hardware 通过 ID 和槽 8 工作，源码没有消费 backend_type 的识别表。App 和主站均可继续编译使用原有已发布的 v2 头文件；数值登记与监控显示独立于 ABI 包版本。

复验时，给 M2 的 vcan 配置追加 `-DROCOS_CO_CLIENT_SHM_INCLUDE=/path/to/rocos-app/3rdparty/rocos-shm/include`，重新构建后在隔离 vcan 环境运行 CTest。用于验证的接口、SHM ID 和子进程均由测试隔离。
